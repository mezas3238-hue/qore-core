## Hypothesis and falsification tests

A ledger without exact two-sided quotes at entry and exit, immutable source witness, source/account/symbol binding, as-of receipt times, positive spread, **verified 1 unit of price movement -> deposit currency** contract multiplier (including lot size), signed source exchange conversion, explicit commissions in deposit currency both ways, funding/swap in deposit currency, slippage for both orders, and strict linear instrument payoff can NOT output a NET-like research metric. Any absent price/commission/financing/conversion must block; never substitute 0.

- Use `Decimal` for all amounts and refuse binary float or bool in monetary inputs.
- Four causally admissible event times: entry_decision <= entry_receipt? The quote receipt must be <= decision; exit quote receipt <= exit decision; entry_decision < exit_decision. Contract/fees/conversion witness first available <= entry_decision; timestamps must be UTC exactly.
- Contract witness must contain sha256 source and single account pseudonym, canonical asset, provider symbol ID, positive verified quote-currency cash exposure per price unit, quote->deposit FX conversion as of each decision and expiry time, and margin/size terms. No guessed universal point-value for indices/metals/FX.
- **Important accounting distinction:** actual fills already contain slippage, so do not subtract modeled slippage twice. V1 is a quote-reference **stress estimate**, not fill replay. Slippage entered explicitly as non-negative price adverse offsets for entry and exit. Commissions, swap/financing entered separately, measured non-negative in deposit currency; a reported 0 can only come from an explicit source witness field with exact sha/first-known time, never default. Conversion rate applies at exit as a *declared simplifying linear-payoff assumption*, NOT cTrader exact booking system. If conversion changes during a position or non-linear instrument, block rather than infer NET.
- Direction +1 long: entry reference ASK and exit BID, stressed entry=ASK+adverse_entry_slip and exit=BID-adverse_exit_slip. Short -1: entry BID, exit ASK, stressed entry=BID-entry_slip and exit=ASK+exit_slip. Signed gross deposit result = direction*(exit-entry)*verified_quote_exposure*verified_quote_to_deposit_rate.
