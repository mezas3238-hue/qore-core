## 2. Exact defects addressed in this branch

**P0-C1 POSITION_TERMS_DRIFT**: Previously each `Vt08PositionSnapshot` validated long/short price geometry in isolation; later snapshots could silently change `initial_stop`, `bound_destination` or relax a tightened `current_stop`. Gate now freezes original terms at first observed position snapshot and refuses widening between subsequent observations. **Limit:** first observed terms themselves come from the unverified external producer; this establishes continuity, **not physically sourced initial risk**.

**P0-C2 TERMINAL_GHOST_POSITION**: Previously research `EXIT` advice could be given repeatedly without a terminal settlement record; the gate could evaluate ostensibly OPEN snapshots after the external position had closed. `Vt08ResearchTerminalEvidence` and trace now distinguish external simulated terminal close, link fill identity/hash and stop all later position evaluations after actual terminal record. **No automatic close on EXIT advice.**

**P0-C3 CLOCK_DST_FOLD**: Python same-ZoneInfo datetime comparisons can compare wall time and ignore the DST `fold` distinction. The cognitive gate now normalizes global replay, source event decision, simulated fill, position and terminal comparison to UTC. All five-market Situation feature cutoffs and latest-closed M15 comparisons are also UTC-based. Regression includes NY 01:45 fold0 → 01:15 fold1 as legitimate forward time, reverse time forbidden, and same instant NY vs UTC position as-of.

**P0-C4 TYPED_CAUSAL_FLAGS**: Python nonempty string `"false"` evaluates true; this was unsafe for `methodology_valid`, `source_identity_complete`, `h4_lifecycle_valid`, research/broker flags, policy and protection booleans. Explicit exact-bool guard added. Prices and Situation metrics require finite `Decimal` (not unchecked float). Anchor hour requires exact int, not `True == 1`.

**P0-C5 MEMORY_CACHE_MUTATION**: Public `cibo_market_memory_runtime_view` and `trader_experience_runtime_view` returned the **mutable cached dict**, allowing consumers to alter freeze/governance values without changing previously cached fingerprint. Both now deepcopy internal cache. An adversarial regression attempts to mutate authority/self-training flags and verifies fresh views and fingerprints remain unchanged.

**P0-C6 UNSIGNED_REAL_EVENT_INTENTION**: Previously a caller could invoke `evaluate` on a declared valid synthetic/real-looking Situation and see research `EXECUTE` without ever running A/B intake. The explicitly named **`evaluate_provenanced`** gate now enforces the upstream source contract for REAL candidate entry; synthetic `evaluate` remains lab-only, research-only, broker_authorized false. No signed A/B manifest exists; test proves an arbitrary supplied SHA does not unlock it. **Operational integration must call the provenanced pathway exclusively**; that integration is pending and must be verified.
