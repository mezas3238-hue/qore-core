# VT31 Gate 1: cognition selection vs earliest raw FVG (preregistered 2026-10-13)

**Registered BEFORE runner, tests and new results.** Hypothesis: a causally selected first qualified VT31 FVG should improve gross directional next-open +15-minute performance vs the earliest raw unfiltered M1 FVG in the same complete ICT window, **without** looking at price outcomes. This is a **selection signal diagnostic**, not CE or net economic PnL, not independent OOS. COG+OPS is measured as a combined stack: the ledger of 2,140 comes AFTER both cognitive and operational gates, so this test CANNOT isolate COG's unique contribution.

**Frozen source:** 1,059,784 NAS100 M1 candles 2023-10-01 through 2026-10-01 exclusive; SHA256 `0563370fd021ad091392eb26f60cda0d3356d38c801fc1c2083cceafc5043cfa`, GitHub Actions artifact `11459859004`. Frozen ORIGINAL cleanroom COG+OPS output artifact `11657461650`, 2,140 source events, 766 London / 721 NY AM / 653 NY PM, zero broker fills. No altered source price or filters.

**Control**: inspect exactly every 60-minute complete original ICT window (NY local 03, 10, 14; DST aware) and take the **first** three contiguous M1 bars whose third-bar low is strictly above first-bar high (LONG) or whose third-bar high is strictly below first-bar low (SHORT). M1 third candle must have CLOSED **before** window end, mirroring OPS. Select first source only (never choose the candidate with best hindsight return). No COG, no target, no MSS, no CE, no broker execution. This raw comparator deliberately differs in direction and/or timestamp and is not an exact causal ablation of COG.

**Primary matched comparison**: only windows with BOTH approved-source event and first raw FVG and both fully valid 16 M1 forward openings. For each use its OWN source-close timestamp, signed `OPEN(t+15)-OPEN(t)`; report n, mean approved, mean raw, mean **paired difference** and 95% ISO week-block bootstrap 2000 seed 13102026, plus absolute time gaps, direction agreement and exact-identity agreement. A lower bound greater than zero is **exploratory evidence of joint COG+OPS source selection only**, NOT of economic edge or cognitive independence. Time and direction changes are confounds and must be reported in the same table.

**Additional descriptive checks:** raw-FVG in all eligible 2,286 complete windows (or fail if count drifts); number with no raw gap; count where joint stack admitted a first suitable signal vs no source; matched per-session and yearly summaries; show all unmatched events as missing not zero. Compare raw first 15m return in windows with and without later approval: this uses **future membership within window** and is ONLY descriptive, with no trading permission. No selection of NY/London window after results; 15m is fixed, not best among 5/30/60.

**Stop/go gate:** absent a clear, causal, reproducible and robust incremental directional gain from the joint stack under this benchmark, label **NO_SUPPORT_SELECTION_LIFT**. A positive gross matched mean alone does NOT prove it. Even if gate is descriptively positive, demand an exact same-timestamp, same-direction raw opportunity universe with explicit COG-only adjudications plus separate OOS before calling cognitive edge. No parameter iteration. Do not alter any branch's existing VT31/G3 code, main, G3 signatures, holdout, broker orders or VPS. All results remain development/posthoc, not OOS.
