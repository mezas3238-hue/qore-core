# VT31 NAS100 — Post-Entry Causal Market-Fact Ledger Gate 001

**Status:** PREDECLARED OBSERVATION-ONLY PREPARATION GATE  
**Baseline:** `VT31_AB_COMP009_MAX_INTELLIGENCE_COMPOSED_SURVIVOR`  
**Execution venue:** independent GitHub Trader Lab  
**Fresh Holdout:** SEALED

## Purpose

Build a reusable consumed-evidence post-entry ledger so market-native
`structure_invalidated`, `liquidity_failure_confirmed` and
`regime_changed_against_thesis` hypotheses can be falsified quickly without
reconstructing the full M1 path on every iteration.

This gate authorizes data preparation only. It grants no new trading action.

## Frozen population

The ledger must reconstruct exactly the Comparator-009 admitted population in
each retained consumed partition:

- R5;
- R6;
- R8;
- recent consumed.

The population identity must match the frozen Comparator-009 binding.

## Per-trade frozen geometry

For every admitted trade persist only information available from the original
causal setup:

- side;
- entry family;
- entry price;
- initial structural stop;
- primary structural target;
- source structural level;
- source swing extreme;
- selected entry-evidence zone lower/upper;
- reference high/low;
- original decision timestamp;
- entry causal context.

## Per-observation causal trace

For every fully closed M1 observation already reached by the Comparator-009
post-entry cognition, persist:

- observation timestamp;
- current closed price and current open-R;
- H4/H1/M15 state;
- management context;
- destination state;
- protection urgency;
- path efficiency / overlap already computed by the frozen cognition;
- reference reclaim age and existing freshness bucket;
- last causal structure-event family, source and age;
- whether the closed price is back through the frozen source structural level;
- whether the closed price has failed through the selected entry-evidence zone
  against the thesis;
- whether the closed price is beyond the adverse reference boundary;
- existing Comparator-009 exit authorization flags;
- **next M1 open R**, computed from the frozen entry and initial structural
  risk, for later counterfactual execution at the only causally valid next open.

The next-open value is an execution consequence, never decision authority.

## Causality

For an observation at M1 close T:

- decision fields may use only bars closed at or before T;
- the next-open execution value is attached only for evaluating a decision
  already made at T;
- no next-bar high, low or close may influence the decision;
- terminal outcome, partition identity and historical date may never become
  runtime authority.

## Discovery restrictions

The observation phase may compare eventual winners and losses to identify
candidate market facts, but any resulting runtime hypothesis must be separately
predeclared before economics are replayed.

No newly mined numeric threshold may be promoted.

Prefer categorical / geometric market facts whose semantics exist independently
of terminal PnL.

## GitHub Trader Lab independence

The reusable preparation belongs to the independent branch:

`agent/github-trader-lab-001`

It must not copy the Trader Lab runtime back into the VT31 trader branch.

Prepared-ledger caching may be used. A new experiment adapter must be able to
reuse the ledger without full M1 reconstruction when only downstream
hypothesis logic changes.
