# VT08 Cognitive Expansion — M3 Causal Cautious-State Shield V1 Freeze

Status: **PRE-RESULT / CONSUMED DEVELOPMENT / TEMPORAL FALSIFICATION**

## Purpose

Test whether the pre-existing VT08 Core causal-state model can remove a
meaningful share of loss concentration from the high-density M3 latest-PS
population without market, anchor or side deletion.

The cognitive action is deliberately narrow:

**veto only contexts classified CAUTIOUS by a state table fitted on the
chronological first 70% of that market.**

SUPPORTIVE and MIXED contexts remain admitted.

## Frozen causal features

No new feature or threshold is introduced. Reuse the existing Core Allocation
Frontier V1 axes and thresholds:

- anchor;
- side;
- risk/reference band;
- C2 body band;
- Protected Swing age band;
- reference-H4 body alignment.

State-quality and context-score thresholds are unchanged from the existing
VT08 Core model. Terminal PnL may be used only to fit the first 70% development
state table. The final 30% classification never sees its own outcome.

## Frozen population

- all five markets;
- M3_FRACTAL for every market;
- LATEST_CONFIRMED_PROTECTED_SWING_V1;
- raw equal-risk trade economics;
- original entry, stop, fixed 2R target and H4 lifecycle.

No CIBO management or structural banking is used in this experiment so the
effect measured is admission cognition only.

## Temporal screen

Report on the final 30%:
- baseline trade count / PF / total R / DD;
- retained count / retention rate / PF / total R / DD;
- CAUTIOUS veto count;
- context counts.

A useful development screen requires:
- temporal baseline sample >= 30;
- retained sample >= 30;
- retention >= 70%;
- shield PF > 1.20;
- shield PF > baseline PF;
- shield total R > 0;
- shield DD <= baseline DD.

Passing is not certification. Any survivor must be frozen again and tested on
truly unseen evidence.
