# QORE-UNIVERSAL-TRADER-CERTIFICATION-STANDARD-001 — UTC-001

Status: OWNER-FROZEN UNIVERSAL CERTIFICATION STANDARD
Effective date: 2026-09-28
Applies to all QORE Traders, including QORE_CAPITALIZER_COGNITIVE_SCALPER_V1.
Source of truth: GitHub plus the latest explicit Owner order.

## 1. Constitutional law

UTC-001 certifies excellent Traders, not minimum viable Traders.

Acceptance is conjunctive:

ALL MANDATORY GATES
AND ALL REQUIRED YEARS
AND ALL REQUIRED OOS FOLDS
AND FRESH HOLDOUT.

Absolute rules:
- NO GLOBAL COMPENSATION.
- NO TEMPORAL COMPENSATION.
- NO GATE COMPENSATION.
- EDGE BEFORE DENSITY.
- QUALITY BEFORE QUANTITY.
- SURVIVAL BEFORE SCALE.

Development has zero certification authority.

## 2. Required temporal decomposition

Any multi-year evaluation must expose each 12-month exam year independently.
For a two-year holdout, YEAR_1 and YEAR_2 must both pass.
Every required OOS fold is evaluated independently with the same full gate set.
Global or combined metrics are descriptive only and cannot rescue a failed year or fold.

## 3. Hard gates per required year and OOS fold

| Gate | UTC-001 requirement |
|---|---:|
| Profit Factor | >= 1.50 |
| Expectancy | >= +0.15R/trade |
| Sharpe | >= 1.50 |
| Sortino | >= 2.00 |
| Payoff = Avg Winner / Avg Loser | >= 1.50 |
| Observed Max DD | <= 6R |
| MC positive probability | >= 90% |
| MC p95 Max DD | <= 15R |
| Post-cost PF | > 1.00 |
| Post-cost expectancy | > 0R/trade |
| Loss-cluster survival | PASS |
| Sample sufficiency | PASS |

Boundary law: DD 6.00R passes; DD 6.01R fails.
A positive expectancy smaller than +0.15R fails.
Payoff 1.20 or any compensation exception is no longer accepted.

## 4. Monte Carlo

Each required period must independently include reshuffling, dependence-aware sequence stress, losing-cluster stress, path dependency, and cost stress when valid economic evidence exists.
Hard gate: MC positive >= 0.90 and MC p95 DD <= 15R.
Preferred: MC positive >= 0.95 and MC p95 DD <= 10–12R.
Seed, sample count, chronology, block semantics, and cost basis must be frozen before results.

## 5. Cost certification

Costs may not be invented.
Required: post-cost PF > 1.00 and post-cost expectancy > 0.
If provider/broker spread, commission, slippage, latency, or fill evidence cannot be bound defensibly, COST CERTIFICATION = BLOCKED.
Missing cost evidence is a mandatory missing gate, not a fabricated pass.

## 6. Winner preservation

Any intelligence that removes, changes, protects, exits, defers, vetoes, or abstains must report Loss Recall, Winner Count Preservation, Winner-R Preservation, PF delta, Expectancy delta, Sharpe delta, Sortino delta, DD delta, Payoff delta, and Density delta.
Hard minimum: Winner Count Preservation >= 80% and Winner-R Preservation >= 90%.
Preferred: >=90% and >=95%.

## 7. MAE/MFE and loser anatomy

Mandatory coverage: MAE winners/losers, MFE winners/losers, MAE-before-MFE, MFE-before-MAE, time-to-MAE, time-to-MFE, time-to-stop, and time-to-target.
Full-stop loser anatomy must use causal evidence available no later than the decision timestamp, including where available regime, session, time, weekday, volatility, liquidity, spread, correlation, cross-market state, HTF structure, sweep, MSS, CISD, displacement, FVG, OB, entry location, distance to invalidation, pre-entry path, and opposing structural evidence.
Future MAE/MFE/outcome values are research labels only and cannot be productive decision features.

## 8. Anti-leakage

Productive feature law: FEATURE_TIMESTAMP <= DECISION_TIMESTAMP.
Prohibited: future outcome inputs, future leakage, future MAE/MFE entry features, repeated holdout mining, outcome-aware sizing, martingale, loss-recovery sizing, and post-result Reserved tuning presented as clean OOS.
Outcome-aware productive/runtime logic or holdout mining is a REJECTED condition.

## 9. Reserved burn rule

If Reserved has been observed, analyzed, and used to modify architecture, RESERVED = BURNED.
Burned Reserved remains valid for diagnosis/regression/falsification but has zero fresh-holdout authority for later architecture.

## 10. Fresh holdout

Before opening fresh holdout: methodology, parameters, features, thresholds, decision law, HEAD/fingerprint, full-source chronological recompetition, entrant reconciliation, and deterministic replay must all be frozen.
Fresh holdout is opened once.
If it fails, it becomes consumed and cannot be retuned against then reused as fresh.
Every year/fold inside fresh holdout must pass UTC-001 independently.

## 11. Structural diagnostics

Report diagnostics by session, symbol, direction, regime, volatility state, liquidity state, setup subtype, day-of-week, and time-of-day.
These diagnostics never replace annual/fold gates.

## 12. Density

Density is evaluated only after quality.
No fixed trade-count target has certification authority.
The final minimum sample requirement must be predeclared before fresh holdout and statistically defensible.

## 13. Shared and CIBO

Shared may provide timestamped causal facts/context but is not Trader decision sovereignty.
Scalper owns edge, entry, direction, structural stop, target, and exit methodology.
CIBO owns capital, sizing, allocation, reserve, expansion, recycling, and de-risking.
CIBO cannot certify a weak Trader.

## 14. Classification

ACCEPTED: every mandatory gate passes for every required year/fold and Fresh Holdout passes.
INTERVENTION — CONTINUE ENGINEERING: real edge exists but one or more mandatory gates fail or are missing without terminal falsification.
REJECTED: the tested architecture is terminally falsified, including decisive OOS collapse, unacceptable tail survival, Fresh Holdout falsification, leakage/overfitting dependency, holdout mining, or outcome-aware productive logic.

## 15. Evidence pack

Required before certification request: HEAD, branch, workflow IDs, artifact IDs/hashes, dataset provenance, Development/Validation/Reserved/Fresh Holdout windows and status, per-year full table, per-fold full table, winner preservation, MAE/MFE, loser anatomy, cost stress, sample sufficiency, Fresh Holdout audit, anti-leakage audit, Risk Review, CIBO Review, and Independent Validation.
Global metrics belong only in a descriptive appendix.
