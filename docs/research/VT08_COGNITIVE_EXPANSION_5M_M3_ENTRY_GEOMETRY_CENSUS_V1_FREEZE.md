# VT08 Cognitive Expansion — M3 Entry Geometry Census V1

Status: **OUTCOME-BLIND ENTRY-GEOMETRY CENSUS / CONSUMED EVIDENCE**

The intracycle C2 census proved that source-observable important-level run +
CISD + Protected Swing structures are abundant, while the ultra-narrow
confirmation-close-inside-one-FVG contract is sparse.

This census does **not** invent an entry family. It decomposes what is
mechanically observable, causally, around every intracycle M3 Protected Swing:

- source CISD + Protected Swing;
- positive risk geometry if confirmation close were merely observed as a price;
- zero/one/multiple still-active pre-confirmation FVG zones;
- confirmation touch/close relation to those zones;
- next-M3-open relation to an already-known active FVG;
- later same-H4 causal retest of an already-known FVG;
- later same-H4 causal retest of the already-known CISD level.

A later retest is counted only when that retest itself occurs; it is not used to
authorize an earlier fill. No stop, target, PnL, win/loss, MFE or MAE is read.

Because Owner governance caps selected/pending/filled/terminal trades at one per
market/New-York date, every category reports both raw event count and distinct
NY-date count. Distinct-date density is the relevant upper-bound diagnostic for
an eventual executable family under current Owner policy.

Nothing in this census changes the current authority table. The five
non-positional families remain SOURCE_IDENTITY_ONLY until exact provenance-bound
entry + stop + target bundles are frozen.
