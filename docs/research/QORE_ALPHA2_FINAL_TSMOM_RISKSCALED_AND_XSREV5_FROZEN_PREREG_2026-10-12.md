## Fixed methodology A: FINAL TSMOM252-RISK
- Each of **all 33** original signed source markets, SHA entire 11-year RAW/QUALITY and signed33 manifest BEFORE any pre-embargo OHLC. UTC weekdays only, >=12 original M5 per day, first observed native M5 open and last observed close, no imputation/forward fill. Eligible source-days can be missing or shorter than a real provider session: not equal to broker daily close.
- On first eligible source weekday of ISO week, with no overlapping previous open holding, signal LONG/SHORT = sign(prior session close minus close **252 previous eligible sessions earlier**). Zero -> no trade. Signal available only before the first M5 day open as **model reference**, which does NOT prove any broker achievable latency.
- Past 20 close-to-close **log-return** daily observations ending prior to current entry day, sigma = sample stdev(log(C_k/C_{k-1})) of these 20; realized annual vol = sigma * sqrt(252). Missing/zero/nonfinite sigma => no position. **Annual target volatility 10%, exposure magnitude min(3.0, 0.10/annual_sigma)**. This 3x cap is predeclared and fixed; report cap-hit rates. No alternate cap, target, lookback, vol-window or execution time after outcomes. Only previous data used for sigma.
- **Position is opened and closed each week**, reference entry at the first source-day M5 OPEN, exit last source M5 CLOSE on the fifth eligible session including entry. Retain entry/exit day and source native bar counts, zero/holiday/range gaps; never cross era boundaries or embargo and never clip to an earlier exit.
- Gross reference weekly instrument return in bps = signed weight * 10000 * (exit_close / entry_open - 1). Explicit user-requested **assumed cost 1 bp per side** on opened+closed notional = 2*abs(weight) bps per trade. NET_COST_PROXY = gross minus assumed cost; NOT genuine broker net. No commission/swap/funding/latency account proof; gross and cost proxy separate.
