## Structural DOL ladder

For a long trade:

- DOL1 = opposite frozen 09:00 reference boundary;
- DOL2 = DOL1 + 0.25 x frozen reference width;
- DOL3 = DOL1 + 0.50 x frozen reference width;
- DOL4 = DOL1 + 1.00 x frozen reference width.

For a short trade, the offsets are mirrored downward.

These are structural price destinations, not sizing rules.

## DOL1 touch vs acceptance

A touch is not acceptance.

### DOL1 touch

First causal M1 bar whose high/low reaches DOL1.

### DOL1 accepted

After the first touch, a **fully closed subsequent M1 bar** must close beyond
DOL1 in the trade direction.

Acceptance becomes known only at that close.

### DOL1 rejected / retested

Record separately:

- no accepted close beyond DOL1;
- close returns back inside the primary boundary;
- methodological invalidation;
- lifecycle termination.

No immediate DOL1 lock is assumed.
