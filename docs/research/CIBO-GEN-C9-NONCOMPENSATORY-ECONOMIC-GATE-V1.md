## Principle

GEN-C9 does not maximize return in isolation.

Higher growth may not compensate for worse survival, tail drawdown, capacity
breaches, plausible loss, recovery or minimum realized capital.

No weighted score is allowed.

## Safety dimensions

A treatment must be no worse than the current control on the same scenario set
for all of:

- ruin path count;
- capacity-breach path count;
- p99 maximum drawdown;
- maximum drawdown;
- maximum time underwater;
- p95 recovery time;
- maximum peak plausible loss;
- minimum realized capital;
- minimum ending capital;
- positive-ending-delta path count.

Any deterioration rejects the treatment from further GEN-C9 promotion.

## Strict economic improvement

After all safety dimensions pass, the treatment must improve strictly at least
one of:

- median ending capital;
- minimum ending multiple;
- median ending multiple;
- minimum return / peak plausible loss.

This gate intentionally does not specify a target such as +491%, +1473%,
+1964% or +2000%.

World Cup figures remain an external capability exam, never a fitting target.

## Result

Passing means only:

`ELIGIBLE_FOR_FURTHER_RESEARCH`

It does not mean:

- winner;
- production policy;
- certification candidate;
- certified.

Multiple treatments may survive simultaneously.

Fresh OOS, adversarial stress and temporal replication remain mandatory.
