## 3. Current semantic gaps

### GAP-STI-001 — proactive cognition has no typed output boundary

Shared has rich internal cognition contracts but no canonical Trader-facing
machine object that compresses world knowledge into evidence-bound,
time-bounded intelligence.

**Severity:** CRITICAL

### GAP-STI-002 — opportunity discovery can be confused with setup generation

CIBO contains its own opportunity-search concepts, while Shared currently has
no explicit distinction between:

```text
MARKET DESERVES ATTENTION
vs
TRADER HAS A VALID SETUP
```

**Required invariant:**

```text
SHARED OPPORTUNITY != TRADER OPPORTUNITY ENVELOPE
```

### GAP-STI-003 — no world-at-entry lineage

There is no Shared-owned immutable reference linking an open Trader position to
the Shared world snapshot observed at entry.

Without this, deterioration/continuation cannot be measured causally.

### GAP-STI-004 — no position-threat state machine

Shared cannot currently express a typed transition from world coherence to
thesis weakening while proving that the output carries no exit/stop authority.

### GAP-STI-005 — no alert identity/lifecycle

Repeated cognition could be emitted as repeated messages without a stable
hypothesis/alert lifecycle.

### GAP-STI-006 — no causal fast-path contract

The architecture requires precomputed Shared state, but there is no explicit
Trader-facing snapshot contract that rejects future evidence and stale/invalid
provenance.

### GAP-STI-007 — no calibrated-confidence distinction

Current Shared components carry confidence/uncertainty metrics, but STI needs
to distinguish a bounded raw support metric from empirically calibrated
confidence.

### GAP-STI-008 — no relevance/routing boundary

There is no read-only Trader capability registry for routing by market,
horizon and intelligence class without importing Trader methodology.

### GAP-STI-009 — no materiality/dedup contract

Without explicit transition rules, proactive Shared can become an alert-spam
system.

### GAP-STI-010 — no incremental-value certification

No current artifact proves that proactive Shared improves discovery, entries or
position management. Productive utility claims are therefore forbidden.
