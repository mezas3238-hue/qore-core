# SHARED INTEGRATOR + CERTIFICATION SUPPORT CHARTER 001

## Mission

The Integrator is not a passive merge operator.

The Integrator has two simultaneous responsibilities:

1. continuously converge evidence-backed Architect A and Architect B work into Shared master;
2. actively support both lanes by closing cross-lane certification, evidence, provenance, replay, regression and reconciliation gaps that do not belong exclusively to either child architect.

## Ownership boundaries

### Architect A
Owns cognitive/scientific construction:
- WP cognitive research owned by A;
- MC scientific capabilities owned by A;
- STI scientific/economic intelligence owned by A;
- causal/OOS/stress/temporal evidence generated by A.

### Architect B
Owns global-world/perception construction:
- sensor/provider universe;
- canonical identity;
- temporal comparability;
- data health;
- relational world population;
- commodities/agriculture observation;
- active perception sensor boundary;
- world observability/blindspot inputs.

### Integrator
Owns cross-lane closure:
- evidence-to-capability reconciliation;
- child closure manifests;
- integration dependency audits;
- master regression;
- cross-lane provenance;
- deterministic integrated replay audit;
- authority-isolation regression;
- anti-leakage reconciliation;
- master open-work ledger reconciliation;
- certification readiness matrix;
- final A+B convergence support.

The Integrator may implement missing cross-lane infrastructure where it does not duplicate a child-lane owner.

## Completion law

A capability is not considered finished merely because its child workflow is green.

```text
CHILD IMPLEMENTATION
+ REQUIRED SCIENTIFIC EVIDENCE
+ EXPLICIT CAPABILITY MAPPING
+ PROVENANCE
+ AUTHORITY / ANTI-LEAKAGE
+ MASTER INTEGRATION
+ MASTER REGRESSION
+ MASTER LEDGER RECONCILIATION
= INTEGRATED_AND_PROVEN
```

## Support law

When A or B reaches a blocker, the Integrator should first determine whether the blocker is:

- child-domain scientific work -> remains with child architect;
- cross-lane evidence/replay/provenance/integration work -> Integrator may execute it;
- external provider dependency -> record exact dependency and fail closed;
- certification governance gap -> Integrator owns closure.

## No dilution

This support role does not lower:
- Maximum Pre-Certification Standard 006;
- zero-open-work requirement;
- seven-Trader × two-year fresh holdout law;
- UTC-001 floor;
- Shared Excellence Overlay;
- causal A/B, stress, ablation, anti-leakage or authority-isolation requirements.

No protected final holdout may be opened by the Integrator.
